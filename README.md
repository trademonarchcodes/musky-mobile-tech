# MUSKY MOBILE TECH

Premium black-and-gold gadget storefront built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Project structure
- `index.html` — page content and structure
- `css/style.css` — responsive visual system and animations
- `js/main.js` — mobile navigation and reveal interactions
- `assets/` — optimized brand logo and store product photo

## Before launch
- Confirm the official business address and opening hours, if they should appear.
- Add real product listings, prices and availability when supplied by the business.
- Replace or supplement remote Unsplash images with approved product photography.
- Test the WhatsApp link and all sections on target devices.

## Deploy
This is a static site and is compatible with GitHub Pages and Cloudflare Pages. On Cloudflare Pages, choose the repository and use the root directory `/`; no build command is needed.
